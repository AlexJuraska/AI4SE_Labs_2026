All three frameworks were found on the provided website https://frompting.com/frameworks

**APE** - Action Purpose Expectation <br>
I chose APE because it's simple, so it should give clean SQL queries without too much extra explanation

**RTF** - Role Task Format <br>
The ability of giving the model an SQL expert role should make it more accurate with better queries.
 
**STAR** - Situation Task Action Result <br>
STAR because gives the model the most context about the problem, therefore it should handle the questions better.
